Launch Radar: a token launch radar that scores pre-token protocols (points programs with no token yet) by implied launch value, ranks them on a board, and generates a static dashboard from the same data. Node 22, standard library only.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
